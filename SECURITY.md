# Security policy

Security fixes currently target the latest code on the default branch. There are no supported historical release branches yet. See the [security model](docs/security.md) for controls, boundaries and known limitations.

Please do not publish credentials, exploit details, private targets or database dumps in public issues. Use the repository's **Security → Report a vulnerability** private reporting option if enabled. If it is unavailable, contact the [maintainer](https://github.com/timmsy1998) to establish a private channel without posting vulnerability details publicly.

Include the affected revision, deployment mode, minimal reproduction, expected impact and proposed mitigation if available. Redact secrets and personal data. We will assess reports and coordinate a fix/disclosure; no guaranteed response deadline or bug bounty is offered.
